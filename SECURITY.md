# Security

To report a security problem, use **Report a vulnerability** on the repository's [Security tab](https://github.com/Kaepora-HQ/kaepora/security). The report stays private until it is fixed.

Do not open a public issue for it.

Kaepora reads one file from the internet: the newest release's `latest.json` on GitHub, to say when a newer version is out. It asks each time it opens with **Check for new versions** ticked, and when you tick that box. A problem in a download, in that request, or in what Kaepora writes into the emulator's mods folder is worth a report.
